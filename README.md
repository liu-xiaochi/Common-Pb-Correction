# 普通 Pb（Common Pb）校正程序

`pbcorr` 是一个**面向 LA-ICP-MS U-Pb / U-Th-Pb 定年**的普通铅校正工具，根据本目录下已有的
Excel 表格设计：算法、模型参数、判据和表格格式都取自项目内的实际数据，并用这些数据做过回归验证。

- 三种校正方法：**207Pb 法**、**总 Pb 三维迭代法（Mottram 2018 思路）**、**Tera-Wasserburg 截距法**
- 普通 Pb 组成：**Stacey-Kramers 两阶段模型**（可选“现今组成”或“样品年龄时组成”）或任意固定组成
- 误差：Monte-Carlo 传播 206/238 与 207/235 的**相关误差**，输出 2σ
- 输入：直接读 Excel（`.xlsx` / `.xls` / `.csv`），自动识别表头，**不用改你现有的表**
- 输出：`校正结果` + `样品汇总` + `计算参数` 三个工作表，可选 T-W 图与年龄分布图
- 界面：双击 `启动GUI.bat` 即可用；也可以命令行/脚本调用

## 1. 快速开始

### 图形界面（推荐）

双击 **`启动GUI.bat`**，或在本目录执行：

```bat
python -m pbcorr gui
```

1. 选输入文件 → 选工作表（程序会自动识别表头）；
2. 选校正方法（默认 207Pb 法）；
3. 点“开始校正”，结果表和图件自动生成。

![界面](界面截图.png)

“单点计算”页可以手工输入一个分析点，立刻看到 f206、各比值校正结果和 T-W 图；
“方法说明”页内置了公式、适用条件和判据。

### 命令行

```bat
:: 生成输入模板
python -m pbcorr template -o 输入模板.xlsx

:: 批量校正：207 法
python -m pbcorr run 数据.xlsx --method 207 --out 结果.xlsx --plot

:: 高普通 Pb 独居石：总 Pb 迭代法
python -m pbcorr run 数据.xlsx --method total --mode at_age --plot

:: 单点计算
python -m pbcorr calc --r68 0.0029859 --e68 8.31 --r75 0.0273863 --e75 27.38 ^
    --rho 0.64 --r208 0.000870179 --e208 5.32 --u 7521.24 --th 55746.4 --method total

:: 看看某个表能不能识别
python -m pbcorr list 数据.xlsx
```

> `--e68/--e75` 等误差参数是 **2σ 相对误差（百分数）**，与表格里的 `2s%p` 一致。

## 2. 三种方法怎么选

| 方法 | 适用对象 | 前提 | 代码 |
|---|---|---|---|
| **207Pb 法** `--method 207` | 普通 Pb 较低的锆石、独居石（f206 < 20%） | 样品谐和；普通 Pb 组成已知 | `correct._engine_207` |
| **总 Pb 迭代法** `--method total` | 普通 Pb 很高（f206 30–90%）的独居石 | 有 208Pb/232Th 与 Th、U；以 208/232 年龄为锚 | `correct._engine_total` |
| **T-W 截距法** `--method tw` | 同一岩浆事件的样品群，普通 Pb 变化大 | 样品群同时代、普通 Pb 组成一致 | `correct.correct_tw` |

**判据**：`f206 = 普通 206Pb / 总 206Pb`

- `< 20%`：207 法可靠；
- `20–50%`：207 法对普通 Pb 组成假设敏感，结果仅供参考；
- `> 50%`：建议改用总 Pb 法或 T-W 法；
- `> 100%` 或 `< 0`：数据不自洽，程序自动标“剔除”。

## 3. 算法要点

### 3.1 207Pb 法（对应 `09FW132 年龄.xls`）

以测得的 206Pb/238U 年龄 *t* 为起点，算理论放射成因比值：

```
r76_rad(t) = (e^(λ235·t) − 1) / [137.818·(e^(λ238·t) − 1)]
f206       = (r76_meas − r76_rad) / (r76_common − r76_rad)
(206/238)corr = (206/238)meas · (1 − f206)
```

扣除后重算年龄、再迭代，直到 *t* 稳定。与工作表里的 `207/206*`、`f206` 列完全对应
（但本程序逐行用各自的年龄，而不是全表共用一个 `207/206*`）。

### 3.2 总 Pb 三维迭代法（对应 Mottram 表与 Huixia 的 docx）

以 208Pb/232Th 年龄（对普通 Pb 最不敏感）为锚：

```
Δ(207/235)     = (207/235)meas − (e^(λ235·t) − 1)
(206/238)com   = Δ / (137.818 · r76_common)
(208/232)com   = r86_common · (206/238)com · (238U/232Th)原子
```

扣掉普通 Pb 后重算 208/232 年龄，再回到第一式，迭代到 **207/235 与 208/232 年龄一致**。
这正是 docx 里“两步即收敛”的过程。

### 3.3 Tera-Wasserburg 截距法

在 `238U/206Pb`—`207Pb/206Pb` 图上，按样品分组作**过普通 Pb 组成点 (0, 207/206_c)** 的加权回归，
直线与谐和线的**下交点**即年龄。斜率由各点 `s_i = (y_i − y0)/x_i` 的加权平均求得，
误差按相关误差传播；与谐和线求交用向量化二分法。

### 3.4 普通 Pb 组成

```
Stacey-Kramers (1975) 两阶段：
  4.57–3.70 Ga : μ = 7.19, Th/U = 4.62
  3.70 Ga–现在 : μ = 9.74, Th/U = 3.78
  初始(4.57 Ga): 206/204 = 9.307, 207/204 = 10.294, 208/204 = 29.487
  现今         : 18.700 / 15.628 / 38.630
```

注意 207 的演化用的是 **235U/204Pb = μ/137.818**（这是两阶段模型最容易写错的地方，
程序里已按此实现，并与 `Pb isotope evolution -two stage model2.xls` 逐点对上）。

“样品年龄时的组成”比“现今组成”更严格：0.42 Ga 时 207/206 会从 0.8356 变为 0.8643，
对老样品不可忽略；对 < 50 Ma 的样品两者几乎一样。

### 3.5 误差传播

1. 把表格的 `2s%` 转成 1σ 相对误差；
2. 对 `ln(206/238)` 与 `ln(207/235)` 按 Isoplot 的 Rho 联合抽样；
3. 每个 Monte-Carlo 试验**完整走一遍迭代**（包括普通 Pb 组成随年龄变化）；
4. 取 1σ 标准差 × 2 作为 2σ，同时给出 f206 的误差。

`Rho` 的定义与 Isoplot 相同，并可由三个比值误差反算（程序内置此校验）：

```
ρ = (σ68² + σ75² − σ76²) / (2·σ68·σ75)
```

## 4. 输入格式

最小要求：表头出现在**前 12 行**内，且至少含 **206Pb/238U** 与 **207Pb/235U**
（或 **207Pb/206Pb**）。

| 列 | 是否必需 | 说明 |
|---|---|---|
| Sample / 样品 | 建议 | 用于分组汇总；缺省记为“未命名” |
| Grain / Spot / Comment | 可选 | |
| U、Th、Pb (ppm) | 总 Pb 法必需 | Th、U 用于普通 208Pb 换算 |
| 206Pb/238U + 误差 | **必需** | 也接受 `238U/206Pb`（自动取倒数） |
| 207Pb/235U + 误差 | 二选一 | |
| 207Pb/206Pb + 误差 | 二选一 | 若同时存在，以 207/235 为准（见下） |
| Rho | 可选 | 默认 0 |
| 208Pb/232Th + 误差 | 总 Pb 法必需 | 也接受 `208Pb/232Th Age (Ma)`，自动反算比值 |

误差列自动识别：`2s%p`（2σ 相对%）、`2s%`、`1sigma`（1σ 绝对）、`2s ab`（2σ 绝对）、`σ` 等。

> **为什么要以 207/235 为准**：项目附录表的 `207Pb/206Pb` 列与 `207Pb/235U`、`206Pb/238U`
> 互不自洽（相差约 100 倍），而 `207/235` 与 `206/238` 是自洽的。程序因此用
> `207/206 = (207/235)/(206/238)/137.818` 导出，避免被错误列带偏。

## 5. 输出

| 工作表 | 内容 |
|---|---|
| `校正结果` | 每个分析点：实测比值、f206/f208、扣除的普通 Pb、校正后比值、四个年龄及 2σ、推荐年龄、状态与说明 |
| `样品汇总` | 按样品加权平均年龄、MSWD、拟合概率（T-W 法为各组截距年龄） |

结果表带条件填色：红=剔除，黄=普通 Pb 较高，浅橙=有提示。

## 9. 局限与注意

1. **207 法假设谐和**。若样品本身不谐和（继承 Pb、Pb 丢失），校正后的年龄仍无地质意义；
   请结合 T-W 图与 207/206、206/238、208/232 三个年龄的一致性判断。
2. **普通 Pb 组成是最大不确定源**。f206 越高，结果对 `206/204、207/204、208/204` 越敏感；
   这一部分误差**没有**计入 2σ（属于系统误差）。
3. **总 Pb 法以 208/232 年龄为锚**，若独居石存在明显的 Th-U 不平衡（初始 230Th 过剩），
   206/238 与 207/235 会系统性偏老（本项目的 18.6 vs 17.1 Ma 即属此类），
   此时 208/232 年龄更接近真实年龄。程序把这一差异作为提示，不做 Th 不平衡校正。
4. **T-W 法假设同组样品同时代、普通 Pb 组成一致**；MSWD 很大时应检查分组是否合理。
5. 程序不处理 `Data Comm Pb Correction` 里的 207/208 型（Khan）校正，也不处理
   `独居石过剩206Pb校正` 的 230Th 不平衡校正（那是另一类问题，不属于普通 Pb）。
6. 所有年龄误差为**分析误差**，不含衰变常数误差、普通 Pb 组成不确定度、外部重现性。
